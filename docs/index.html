VDS Planner documentation

The VDS Planner plans the change from vSphere standard switches to distributed switches (VDS) for one vCenter. It reads the inventory of the vCenter, checks the plan against design rules and generates a PowerShell package that makes the change with VMware PowerCLI. The planner is one HTML file. It needs no install, no server and no network connection.

Requirements

PartRequirement
PlannerMicrosoft Edge or Google Chrome. Other browsers work, but Save downloads a file and the recent project list is not available.
ScriptsWindows PowerShell 5.1 or PowerShell 7, VMware PowerCLI 13 or later (VMware.VimAutomation.Core and VMware.VimAutomation.Vds).
vCentervSphere 8. A user with the permissions to make VDS and port groups and to change host networking.
InventoryThe inventory workbook (.xlsx) of the vCenter (full, or the network sheets vSwitch, vPort, vNIC, vSC_VMK, dvSwitch, dvPort, vHost), CSV exports of those sheets, or the export of Export-VssLayout.ps1.
