VDS Planner: internal test report

This report records the tests that were done before the live test, the defects that the tests found, and the items that only a live test can cover. The tests used made-up data. No test connected to a vCenter.

Result: ready for the lab test
  • All internal tests pass: planner self-test 83 of 83, offline script tests 148 of 148 and Pester 55 of 55 on PowerShell 5.1 and on PowerShell 7.6, PowerCLI Core parameter check 113 of 113.
  • The workbook chain (converter, project file, name repair, simulation) is tested with a synthetic workbook. It also ran on five real vCenter inventories. Those results hold environment data, so they stay with the data owner, not in this repository.
  • The planner reads the inventory workbook itself (full, network sheets only, or CSV exports of the sheets). On five real vCenter inventories it gives the same inventory as Export-PlannerInventory.ps1, row for row, on PowerShell 5.1 and 7 (tests\Test-PlannerWorkbook.ps1). It reads the largest workbook in less than one second.
  • Open before the pilot: the live test checklist (docs/vds-planner-live-test.html) on a lab vCenter, and the parameter check with the PowerCLI VDS module installed.

2. Defects found and corrected

IDSeverityDefectEffect in a live runCorrection
DF-01majorIn the live check function, a local variable had the same name as the plan parameter (PowerShell names are not case-sensitive).A second run stopped with a false block. The port group name check and the IP address check did not run.Variable renamed. Tests for a second run, name clash and IP in use.
DF-02major$PSScriptRoot is empty in a parameter default under powershell.exe -File (Windows PowerShell 5.1).All scripts failed when started from a scheduled task or another script.Default set in the script body in 8 scripts. Static test added.
DF-03majorDistributed port group names must be unique in a datacenter. One VDS for each cluster gives the same names.The second VDS in a datacenter failed during the change window.Planner check (block in a draft, warning across drafts), name prefix button, preflight block before any change.
DF-04majorNo check of the ESXi version against the VDS version.Hosts before ESXi 8.0 U3 could not join a VDS 8.0.3. The run failed after the VDS was created.Export has the ESXi version. Planner and preflight block.
DF-05majorExport-Csv in PowerShell 5.1 writes ASCII.Names with special characters became ? in the export and the logs.-Encoding UTF8 on all 8 CSV writes. Test with a non-ASCII name.
DF-06major-WhatIf also skipped the output folder and the transcript in the seed scripts.-WhatIf runs failed or wrote no log.-WhatIf:$false on the log writes.
DF-07minorRead-only checks ran between changes.A run could stop after some changes.All checks run first. A blocking item stops before any change.
DF-08minorInventory import cleared the file list too early.Import did not finish.Corrected.
DF-09minorGenerate again used the new draft name after a rename.File names did not agree with the launcher.Base name kept at commit.
DF-10minorSync did not update a VLAN that the operator did not change.Stale VLAN after a refresh.Corrected. Operator changes stay.
DF-11minorSHA-256 needed a browser feature that is not always available.Commit failed in some browsers.Built-in SHA-256, tested against known values and PowerShell.
DF-12minorV-rule numbers in help text were not the numbers of the guide.Wrong references.Corrected.
DF-13minorImport history counted new clusters as changes.Wrong count.Corrected.
DF-15majorTwo runs in the same second used the same transcript and log file name.PowerShell 7: the second run failed. PowerShell 5.1: the second run replaced the log of the first run (lost audit record).Milliseconds in all log file names.
DF-16minorPowerShell 7 changes the ISO commit time of the plan into a local date.The commit time in the output and the logs was in a different format.The plan reader keeps the ISO text. Test added.
DF-17majorThe planner needed one check box for each port group that is not on all hosts (V-05).A large vCenter had more than 1,000 of these port groups. The planner was not usable for it.Trunk check for a full VDS, one check line for each VDS.
DF-18minorThe converter lost the count of a vCenter with one existing VDS (an if statement returns one item, not an array).Wrong count in the summary.Corrected.
DF-19minorThe converter wrote empty CSV files for a vCenter with nothing to convert.The planner refused the empty files.No empty files. A message tells that there is nothing to convert.
