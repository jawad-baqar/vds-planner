Run steps

Do each step under the change control of your organization. Do the steps on one cluster first (pilot).

  1. Put the four package files in one folder on the jump host. Before the change window, run .\Invoke-shared-db-vds-v1.ps1 -Part Check. Correct all blocking items.
  2. Run .\Invoke-shared-db-vds-v1.ps1 -WhatIf. Examine the output.
  3. Run .\Invoke-shared-db-vds-v1.ps1. Log in with the vCenter administrator. The script creates the VDS and the port groups and adds the hosts with no uplink.
  4. For each host, one host at a time: Move-HostToVds.ps1 -Stage 1 (one uplink to the VDS).
  5. For each port group: Move-VmNetworkToVds.ps1 (VM adapters, with a rollback CSV).
  6. For each host, one host at a time: Move-HostToVds.ps1 -Stage 2 (VMkernel adapters and the remaining uplinks).
  7. For each host, one host at a time: .\Invoke-shared-db-vds-v1.ps1 -Part VMkernel -VMHost <host> -WhatIf, then with no -WhatIf. This adds the new VMkernel adapters.
  8. Keep the transcripts and the CSV logs of the output folder with the change record.
